A quiet dhikr reminder, right in your Mac's menu bar.

Zikr speaks a short remembrance of Allah aloud at random moments through your day — Subhanallah, Alhamdulillah, Allahu Akbar, and more. No accounts, no ads, no clutter.

Download for macOS View source on GitHub

Features

Random reminders

Set a min/max minute range and Zikr fires at a random moment inside it — never predictable, never nagging.

Spoken aloud

Each phrase is pronounced in Arabic using the built-in macOS voice, not just chimed or flashed silently.

Notification or flash

Show it as a normal macOS notification, or a soft full-screen flash that fades after a duration you choose.

Launch at login

Optional, using Apple's current SMAppService API — no LaunchAgent files, no background scripts.

Self-updating

"Check for Updates…" pulls the latest GitHub release and installs it in place. No third-party updater.

Private & light

No accounts, no analytics, no network calls except an update check you trigger yourself. Tiny memory footprint.

How it works

1

Install

Download the latest release, unzip, and drag Zikr into Applications.

2

Set your interval

Open Settings from the menu bar icon and pick how often you'd like to be reminded.

3

Let it run

Zikr lives quietly in the menu bar and speaks a remembrance at a random moment — that's the whole app.

What is dhikr?

Dhikr (ذِكْر, "remembrance") is the Islamic practice of remembering God through short phrases of praise and glorification — said quietly throughout the day rather than confined to formal prayer. Zikr brings that habit into a Mac's normal rhythm: a brief, spoken reminder at an unpredictable moment, then it steps out of the way again.

FAQ

Is Zikr free?

Yes. Zikr is free and open source under the MIT license. There are no accounts, subscriptions, or in-app purchases.

Does Zikr need an internet connection?

No, once installed it runs entirely offline. It only reaches the network if you click Check for Updates.

Does Zikr play Adhan or show prayer times?

No. Zikr is intentionally scoped to one thing only: random dhikr reminders. It does not include Adhan, prayer times, Qibla, or any other feature.

Which zikr phrases are included?

A curated set of general, anytime adhkar from the well-known Hisnul Muslim (Fortress of the Muslim) collection, including SubhanAllah, Alhamdulillah, Allahu Akbar, La ilaha illallah, Astaghfirullah, and others.

Does Zikr collect any data?

No. There is no analytics, telemetry, or account system. Settings are stored locally on your Mac.

macOS says it can't verify the developer — is that normal?

Yes. Zikr is signed ad-hoc (no paid Apple Developer account behind a hobby project), so the first launch needs an override: right-click the app → Open, or allow it in System Settings → Privacy & Security. You only need to do this once.
